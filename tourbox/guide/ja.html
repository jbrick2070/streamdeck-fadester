OBS Fadester for TourBox

TourBox で OBS Studio のシーンを選び、手動でフェードし、音量を調整できます。

TourBox を OBS に接続する

  1. Windows 用 ZIP ファイル全体を展開し、展開先のフォルダーで Fadester for TourBox.exe を起動します。Microsoft Store からインストールした場合は、スタート メニューから Fadester Companion を開きます。
  2. OBS を開きます。TourBox Console のプリセットリスト横のインポートボタンから presets/ja/OBS Fadester for TourBox.tb を読み込みます。プリセットを OBS に関連付け、自動切り替え（Auto Switch）を有効にします。読み込むプリセットは、使用する言語のもの一つだけです。 Fadester の TourBox Console にインポート ボタンを使ってください。.tb ファイルはダブルクリックしないでください。
  3. OBS の ツール → WebSocket サーバー設定で、認証を有効にした状態でサーバーをオンにします。OBS Studio 33.0.0 または 33.0.1 で手動フェードを使うには、スタジオモードを有効にし、フェード（Fade）を選び、プレビューとプログラムの間にある白いスライダーを表示したままにします。
  4. Fadester で OBS のシーンと入力を読み込みます。必要に応じて OBS に設定したポートとパスワードを入力します。TourBox Console で OBS Fadester for TourBox を選び、Fadester で設定を保存して操作を開始します。Fadester を開いたまま OBS を前面に戻します。

Windows の表示言語が日本語以外の場合は、Fadester を閉じ、展開先のフォルダーで PowerShell を開いて & '.\Fadester for TourBox.exe' --language ja を実行します。

異なる二つのシーンで試す

  • Scroll ホイールを回すと、プログラムはそのままでプレビューのシーンだけが変わります。押すと両方のシーン名がパネルに表示されます。
  • 平たい Dial をゆっくり回すと、OBS のスライダーが動いて二つのシーンが混ざります。途中で取り消すには、Side を押したまま Dial を押します。
  • Chrome で YouTube 動画を再生します（無料の VJster 拡張機能が必要です）。突き出た Knob を回すと速度が変わり、押しながら回すと微調整できます。押すと動画の状態を確認できます。
  • VJster が操作できるのは Chrome の YouTube だけで、OBS の YouTube ブラウザソースは操作できません。OBS には Chrome のウィンドウキャプチャで表示してください。 音声には Chrome のアプリケーション音声キャプチャを追加してください。
  • Fadester で音楽に使う入力を割り当てます。Side を押したまま平たい Dial を回すと音量を調整できます。Top を押したままの Knob、Scroll、Dial は VJ レイヤー（ブレンドモードと不透明度）を操作します。

TourBox がなければゲームコントローラーで

  1. セットアップタブでXbox または XInput 対応のコントローラーを使うにチェックを入れ、かんたんモードはオンのまま、保存 & 開始をクリックします。プリセットの読み込みは不要です。
  2. OBS でスタジオモードを有効にし、フェード（Fade）を選びます。十字キーの下で OBS の一覧の次のシーンを、上で前のシーンをプレビューに送ります。
  3. 右トリガーを引くと OBS の T バーが追従し、奥まで引くとプログラムに切り替わります。または A を押し続けると、0.15 秒後から押している間だけ T バーが進み、端まで行くと切り替わります。途中で離すとその位置で止まり、もう一度 A を押し続けると続きから進みます。
  4. B でカット、View でプログラムに戻り、左トリガーを押している間は音楽を下げ、十字キーの左右で音楽を調整します。どのボタンもゲームコントローラータブで変更できます。

ミックス全体を調整する

セットアップ画面で OBS ミキサーの全入力をまとめて操作する設定を有効にし、設定を保存して操作を開始します。Side を押したまま Knob を回すとグループ全体の音量が変わります。Tour メニューから、ミックス全体を無音までフェードアウトしたり、前の音量に戻したりできます。ミュート済みの入力はそのままです。

困ったときは

バックグラウンド処理の診断メッセージは英語で表示されます。操作が反応しない場合は、TourBox Console の現在のプリセットと Fadester の操作履歴を確認してください。
