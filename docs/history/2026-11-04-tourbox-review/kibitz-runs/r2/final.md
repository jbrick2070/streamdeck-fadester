# Fadester for TourBox: what ships on Windows

1. First minute: import Show and Tools as additional TourBox Console presets, link both to OBS, run the companion, enable OBS Studio Mode and choose Fade. Scroll cues a real named Preview without touching Program. The flat Dial manually mixes those scenes; stopping partway holds the mix, reversing backs out, and completing a sweep takes it. Tall triggers an automatic Take. Scene navigation requires no named hotkey setup.
2. Controls by feel: the raised Knob rides the assigned music in Show. Side plus Dial rides a separate content input. Tap the Knob for soundcheck, the Dial to read fade position or Scroll to read Preview and Program. For more precision, press and turn Knob or Dial for one quarter the normal step. Press and turn Scroll to browse media. Only Side + Dial press cancels a mix; only Side + Scroll press resets Preview to Program. Leave Side alone silent. Four D-pad anchors, duck/restore music, and undo a level change are separate controls. See tourbox/presets/map.json for exact bindings.
3. Tools: transition and timing choice, cue/media transport including Playlister where supported, overlay visibility, soundcheck, mic mute, screenshot, recording status/chapters and save running replay buffer. Side + Tour cycles between Show and Tools with both linked to OBS. No blind stream or recording stop. Do not assign an unknown source automatically. OBS remains the authority for live state; Console tells you what controls are assigned.
4. Delivery: two native Windows .tb files plus a portable bridge, local control panel with scene/source pickers and activity, clear gallery text identifying the companion dependency, and source. Native shortcut-to-action dispatch against authenticated OBS WebSocket; no Python or user-authored OBS scripts. This is a community preset, not a claim of TourBox certification. The separate YouTube/VJ idea does not ship in the OBS profile.
5. Verification: validate native presets, identify unsupported model capabilities, detect key conflicts, test real bridge against fixture plus read-only controls on installed OBS, and physically confirm the partial dissolve, end-to-end take, all three standalone presses, and same-spindle hold+turn before public claims. Do not manipulate the user's live OBS show during automated review. Limit review to this new tourbox subdirectory and relevant read-only Fadester reference; no external publication or live device access.

6. Registration is all-or-nothing with the conflicting shortcut named. Offer a non-activating feedback strip. Manual phase completion on the target OBS 33 builds briefly resets Studio Mode; verify actual midpoint pixels and rail semantics in an isolated rehearsal. Both native files exist, imported independently. Maintain read-only discovery and opt-in device-specific assignments.
7. Native TourBox 5.12.1 imports and two assigned profiles are verified. The actual OBS 33.0.1 lab has a private desktop/PID/port and verifies partial blend and both rails. Require the packaged Windows listener fixture, stable audio interruption tests, and one physical gesture from the operator. The panel is the launcher, and the companion must be downloadable before the two gallery entries are submitted.
