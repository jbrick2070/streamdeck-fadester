快速入門 · Windows x64

Fadester Companion

使用遊戲控制器或 TourBox 預選 OBS Studio 場景、手動淡入淡出並調整音量。

沒有 TourBox？改用遊戲控制器

  1. 開啟 OBS。在工具 → WebSocket 伺服器設定中啟用伺服器，並保持啟用驗證。接著開啟 Fadester Companion：它會自動連線；若無法連線，視窗會說明該怎麼做。T-bar 需要 OBS 33.0.0 或 33.0.1，並保持 OBS 主視窗開啟且 T-bar 可見。
  2. 在設定分頁勾選使用 Xbox 或 XInput 遊戲控制器，保持勾選簡易模式，再按一下儲存 & 啟動控制。可以略過匯入預設。
  3. 在 OBS 開啟工作室模式並選擇淡入淡出（Fade）轉場。按十字鍵下，將 OBS 清單中的下一個場景放入預覽；按十字鍵上則選上一個。
  4. 扣下右扳機：OBS 的 T-bar 會跟著移動，扣到底即切換到節目。也可以按住 A：0.15 秒後，按住期間 T-bar 會持續推進，推到底即切換到節目。中途放開會停在原處；再次按住 A 即可繼續。
  5. B 直接切換，View 返回節目，按住左扳機時音樂會壓低，十字鍵左右調整音樂。任何按鈕都可在遊戲控制器分頁更改。

工作時請保持此視窗開啟。關閉視窗會停止控制。

連接 TourBox 與 OBS

  1. 從開始功能表開啟 Fadester Companion。若使用 ZIP 壓縮檔，請完整解壓縮，再執行 Fadester for TourBox.exe。
  2. 開啟 OBS。在 TourBox Console 中，使用預設清單旁的匯入按鈕載入 presets/zh-TW/OBS Fadester for TourBox.tb。將預設連結至 OBS，並啟用自動切換（Auto Switch）。只需匯入所用語言的版本。 請使用 Fadester 中的匯入到 TourBox Console按鈕；請勿按兩下 .tb 檔案。
  3. 在 OBS 開啟工具 → WebSocket 伺服器設定，啟用伺服器並開啟驗證。若要在 OBS Studio 33.0.0 或 33.0.1 使用手動淡入淡出，請開啟工作室模式、選擇淡入淡出（Fade）轉場，並讓預覽與節目畫面之間的白色推桿保持可見。
  4. 在 Fadester 讀取 OBS 的場景和輸入來源。視需要輸入 OBS 的連接埠與密碼。在 TourBox Console 選擇 OBS Fadester for TourBox，接著在 Fadester 儲存設定並啟動控制。保持 Fadester 開啟，再切回 OBS。

如果 Windows 使用其他顯示語言，請關閉 Fadester，然後在解壓縮後的資料夾中開啟 PowerShell，執行 & '.\Fadester for TourBox.exe' --language zh-TW。

用兩個不同的場景練習

  • 轉動 Scroll 滾輪可更換預覽場景，節目輸出保持不變。按下滾輪可在面板中查看兩個場景的名稱。
  • 緩慢轉動扁平的 Dial 轉盤，OBS 推桿會移動並混合兩個場景。要取消進行中的轉場，請按住 Side 再按下 Dial。
  • 在 Chrome 中播放 YouTube 影片（需要免費的 VJster 擴充功能）。轉動凸起的 Knob 旋鈕可改變速度，按住轉動可微調，按下可讀取影片狀態。
  • VJster 只能控制 Chrome 中的 YouTube，無法控制 OBS 中的 YouTube 瀏覽器來源。請用 Chrome 的視窗擷取在 OBS 中顯示影片。 請新增 Chrome 的應用程式音訊擷取以取得聲音。
  • 在 Fadester 指定音樂輸入來源。按住 Side 並轉動扁平的 Dial 可調整其音量。按住 Top 時，Knob、Scroll 和 Dial 控制 VJ 圖層（混合模式與不透明度）。

調整整體混音

在設定中啟用 OBS 混音器的所有輸入控制，然後儲存並啟動控制。按住 Side 並轉動 Knob 可調整群組音量。透過 Tour 選單可以將整體混音淡出至靜音，或恢復原有音量。已靜音的輸入來源會保持靜音。

取得協助

背景程序的診斷訊息以英文顯示。若控制沒有回應，請確認 TourBox Console 目前啟用的預設，並查看 Fadester 的活動記錄。
