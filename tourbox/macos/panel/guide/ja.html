Fadester Companion

TourBox で OBS Studio のシーンを準備し、手動でフェードし、音量を調整できます。

はじめて開くとき

Fadester Companion.app をアプリケーションフォルダーに移動します。このアプリは Apple の公証を受けていないため、初回は Control キーを押しながら（または右クリックで）アプリをクリックし、開くを選んでから、もう一度開くをクリックします。または一度開こうとしてから、システム設定 → プライバシーとセキュリティでこのまま開くをクリックします。

TourBox を OBS に接続する

  1. OBS の ツール → WebSocket サーバー設定で、認証を有効にした状態でサーバーをオンにします。OBS Studio 33 で手動フェードを使うには、スタジオモードを有効にし、フェード（Fade）を選び、プレビューとプログラムの間にある白いスライダーを表示したままにします。OBS に保存されたパスワードは Fadester Companion が自動で読み込みます。
  2. Fadester Companion で 1. TourBox プリセットを保存 (.tb)… をクリックし、使用する言語のプリセットを「ダウンロード」など見つけやすい場所に保存します。
  3. 2. TourBox Console を開く（または クリックする場所を見る）をクリックします。TourBox Console でプリセットリスト横のインポートアイコンをクリックし、OBS Fadester for TourBox.tb を開き、Auto Switch をオフにして OBS Fadester for TourBox を選びます。こうすると、前面にあるアプリに関係なく一つのプリセットで操作できます。Auto Switch をオンのままにする場合だけ、Not Linked をクリックして OBS を選び、Save をクリックします。Chrome を前面にして動画を操作するには Google Chrome にも関連付けます。読み込む言語版は一つだけにし、Windows 用のファイルは読み込まないでください。
  4. Fadester Companion にアクセシビリティを許可… をクリックし、システム設定 → プライバシーとセキュリティ → アクセシビリティで Fadester Companion をオンにします。Fadester Companion T-bar と Fadester Companion Shortcuts も表示されている場合は、それらもオンにします。TourBox Console には別の許可が必要です。
  5. 割り当て でシーンと音楽の入力を選びます。保存 & 開始 をクリックし、コントロール: オン になるまで待ちます。Fadester Companion は開いたままにしてください。

Mac 用プリセットでは、OBS の操作に Control + Option + Shift、動画とレイヤーの操作に Control + Shift または Option + Shift を使います。Command は使いません。

異なる二つのシーンで試す

  • Scroll ホイールを回すと、プログラムはそのままでプレビューのシーンだけが変わります。押すと両方のシーン名がパネルに表示されます。
  • 平たい Dial をゆっくり回すと、OBS のスライダーが動いて二つのシーンが混ざります。途中で取り消すには、Side を押したまま Dial を押します。時計回りに回すと、次のトランジションでも常に T バーがプレビュー側へ動きます。トランジションが終わったら、少し間を置いてから回してください。
  • Chrome で YouTube 動画を再生します（無料の VJster 拡張機能が必要です）。突き出た Knob を回すと速度が変わり、押しながら回すと微調整できます。押すと動画を再生・一時停止できます。Side を軽く押すと速度が 1 倍に戻ります。
  • OBS 内の YouTube 動画を直接操作するには、セットアップで動画を入力し、OBS ブラウザソース URL をコピー をクリックして、そのアドレスを OBS のブラウザソースに貼り付けます。
  • Fadester で音楽に使う入力を割り当てます。Side を押したまま平たい Dial を回すと音量を調整できます。Top を押したままの Knob、Scroll、Dial は VJ レイヤー（ブレンドモードと不透明度）を操作します。選んでいないレイヤーは、初めて操作したときに放送中のシーンから自動で決まり（レイヤー 1 = いちばん上の見えている映像、レイヤー 2 = その次）、割り当てに保存されます。
  • Short を軽く押すと録画状態を確認できます（何も変更しません）。音量変更を元に戻す は Tour メニューにあります。

ミックス全体を調整する

セットアップ画面で OBS ミキサーの全入力をまとめて操作する設定を有効にし、設定を保存して操作を開始します。Side を押したまま Knob を回すとグループ全体の音量が変わります。Tour メニューから、ミックス全体を無音までフェードアウトしたり、前の音量に戻したりできます。ミュート済みの入力はそのままです。

困ったときは

バックグラウンド処理の診断メッセージは英語で表示されます。操作が反応しない場合は、TourBox Console の現在のプリセットと Fadester の操作履歴を確認してください。

TourBox による OBS の完全な操作は、Mac ではまだリハーサルで確認されていません。本番の前にテスト用のシーンで練習してください。

macOS が別の言語の場合は、Fadester Companion を終了し、ターミナルで open -a "Fadester Companion" --args --language ja を実行します。
