OBS Fadester for TourBox

用 TourBox 预选 OBS Studio 场景、手动淡入淡出并调节音量。

连接 TourBox 和 OBS

  1. 完整解压 Windows ZIP 压缩包，然后在解压后的文件夹中运行 Fadester for TourBox.exe。
  2. 打开 OBS。在 TourBox Console 中，使用预设列表旁的导入（Import）按钮导入 presets/zh-CN/OBS Fadester for TourBox.tb。将预设关联到 OBS，并启用自动切换（Auto Switch）。只需导入一个语言版本的预设。 请使用 Fadester 中的导入到 TourBox Console按钮；不要双击 .tb 文件。
  3. 在 OBS 中打开工具 → WebSocket 服务器设置，启用服务器和身份验证。要在 OBS Studio 33.0.0 或 33.0.1 中使用手动推子，请进入工作室模式（Studio Mode），选择淡入淡出（Fade）转场，并让预览和输出画面之间的白色推子保持可见。
  4. 在 Fadester 中点击从 OBS 读取场景和输入。如有需要，输入 OBS 的端口和密码。要试用音量调节，请在分配中选择音乐输入源。点击保存并启动控制，在 TourBox Console 中选择 OBS Fadester for TourBox，再将 OBS 切回前台。保持 Fadester 运行。

如果 Windows 的显示语言不是简体中文，请先关闭 Fadester，再从解压后的文件夹中打开 PowerShell，运行 & '.\Fadester for TourBox.exe' --language zh-CN。

用两个不同的场景试一试

  • 转动 Scroll 滚轮可更换预览场景，当前输出画面保持不变。按下滚轮可在面板中查看两个场景的名称。
  • 缓慢转动扁平的 Dial 转盘可移动 OBS 推子，在两个场景之间手动淡入淡出。按住 Side 再按下 Dial，即可取消进行中的转场。
  • 在 Chrome 中播放 YouTube 视频（需要免费的 VJster 扩展程序）。转动凸起的 Knob 旋钮可改变速度，按住转动可微调，按下可读取视频状态。
  • VJster 只能控制 Chrome 中的 YouTube，无法控制 OBS 中的 YouTube 浏览器源。请用 Chrome 的窗口采集在 OBS 中显示视频。 请添加 Chrome 的应用程序音频采集以获取声音。
  • 在 Fadester 中指定音乐输入源。按住 Side 并转动扁平的 Dial 可调节其音量。按住 Top 时，Knob、Scroll 和 Dial 控制 VJ 图层（混合模式和不透明度）。

调节整个混音

如果控制已经启动，请先点击停止控制。在设置中勾选启用 OBS 混音器全部输入控制，然后点击保存并启动控制。按住 Side 并转动 Knob 可整体调节音量。打开 Tour 菜单可将整个混音淡出至静音，也可以恢复之前的音量。已静音的输入源仍保持静音。

帮助

Fadester 桥接程序的诊断信息使用英语。如果控件没有响应，请检查 TourBox Console 当前启用的预设，并查看 Fadester 的活动选项卡。
