VJLink this control

Drives the VJLink plugin for OBS, by BosoVR, through OBS's WebSocket: its presets, BPM tap, blackout and five macros.

This control needs VJLink in OBS. VJLink is free for personal use; see its licence. If the control says VJLink missing, OBS has no VJLink.

VJLink's strobe and flash effects can flash fast. Keep a Blackout key on the deck, and set VJLink's own strobe safety in its web panel.
