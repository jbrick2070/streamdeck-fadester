Fadester Companion

ゲームコントローラーまたは TourBox で OBS Studio のシーンを選び、手動でフェードし、音量を調整できます。

  • ゲームコントローラーXbox などの XInput
  • TourBoxElite、NEO、Elite Plus
  • MIDI コントローラーAPC40 mkII など

TourBox がなければゲームコントローラーで

  1. OBS を開きます。ツール → WebSocket サーバー設定でサーバーをオンにし、認証はオンのままにします。次に Fadester Companion を開きます。自動で接続し、接続できない場合はウィンドウに対処方法が表示されます。T バーには OBS 33 が必要です。OBS のメインウィンドウを開き、T バーが見えるようにしておいてください。
  2. セットアップタブでXbox または XInput 対応のコントローラーを使うにチェックを入れ、かんたんモードはオンのままにします。コントロールは初回、コントローラーなしで自動的に開始します。ウィンドウ左下の停止をクリックしてから開始をクリックすると、コントローラーを使って開始し直します。プリセットの読み込みは不要です。
  3. OBS でスタジオモードを有効にし、フェード（Fade）を選びます。十字キーの下で OBS の一覧の次のシーンを、上で前のシーンをプレビューに送ります。
  4. 右トリガーを引くと OBS の T バーが追従し、奥まで引くとプログラムに切り替わります。または A を押し続けると、0.15 秒後から押している間だけ T バーが進み、端まで行くと切り替わります。途中で離すとその位置で止まり、もう一度 A を押し続けると続きから進みます。
  5. B でカット、View でプログラムに戻り、左トリガーを押している間は音楽を下げ、十字キーの左右で音楽を調整します。どのボタンもゲームコントローラータブで変更できます。

このウィンドウを閉じてもコントロールは止まりません。Fadester Companion は時計の横の通知領域に残ります。止めるには「停止」をクリックするか、そのアイコンを右クリックして「Fadester Companion を終了」を選んでください。

APC40 mkII などの MIDI コントローラーをお持ちですか？

MIDI コントローラーは、Fadester Companion ではなく、OBS 内で動く無料プラグイン Midi Fadester で操作します。Midi Fadester をインストールし、コントローラーを接続して、OBS でツール → Midi Fadesterを開いてください。

  • Akai APC40 mkII：初回は自動で設定されます。クロスフェーダーでプレビューをプログラムへフェードし、フェーダー 1〜8 はオンエア中のシーンのレイヤーに追従し、Fadester Desk ドックが卓全体を画面に表示します。
  • Akai APC mini mk2、Akai MIDImix、Korg nanoKONTROL2、Novation Launch Control XL：コントローラーを変更でそのポートを選ぶと、それぞれ用意されたレイアウトが使われます。これらはベータと表示されており、実機ではまだ確認されていません。
  • その他の MIDI コントローラー：汎用（Generic）レイアウトが使われます。セットアップで 18 本のストリップそれぞれに役割を割り当て、学習を押してフェーダーやノブを動かすと、どれで操作するかを選べます。

TourBox を OBS に接続する

  1. スタート メニューから Fadester Companion を開きます。ZIP を使う場合は、ZIP 全体を展開して Fadester Companion.exe を起動します。
  2. OBS を開きます。TourBox Console のプリセットリスト横のインポートボタンから presets/ja/OBS Fadester for TourBox.tb を読み込みます。自動切り替え（Auto Switch）をオフにして OBS Fadester for TourBox を選びます。こうすると、前面にあるアプリが OBS でも Chrome でもほかのアプリでも、一つのプリセットで操作できます。Auto Switch をオンのままにする場合だけ、プリセットを OBS に関連付け、Chrome を前面にして動画を操作するには Google Chrome にも関連付けます。読み込むプリセットは、使用する言語のもの一つだけです。 Fadester の TourBox Console にインポート ボタンを使ってください。.tb ファイルはダブルクリックしないでください。
  3. OBS の ツール → WebSocket サーバー設定で、認証を有効にした状態でサーバーをオンにします。OBS Studio 33 で手動フェードを使うには、スタジオモードを有効にし、フェード（Fade）を選び、プレビューとプログラムの間にある白いスライダーを表示したままにします。
  4. Fadester で OBS のシーンと入力を読み込みます。必要に応じて OBS に設定したポートとパスワードを入力します。TourBox Console で OBS Fadester for TourBox を選び、Fadester で設定を保存して操作を開始します。Fadester は開いたままにします。

Windows の表示言語が日本語以外の場合は、Fadester を閉じ、展開先のフォルダーで PowerShell を開いて & '.\Fadester Companion.exe' --language ja を実行します。

異なる二つのシーンで試す

  • Scroll ホイールを回すと、プログラムはそのままでプレビューのシーンだけが変わります。押すと両方のシーン名がアクティビティタブに表示されます。
  • 平たい Dial をゆっくり回すと、OBS のスライダーが動いて二つのシーンが混ざります。途中で取り消すには、Side を押したまま Dial を押します。時計回りに回すと、次のトランジションでも常に T バーがプレビュー側へ動きます。トランジションが終わったら、少し間を置いてから回してください。
  • Chrome で YouTube 動画を再生します（無料の VJster 拡張機能が必要です）。突き出た Knob を回すと速度が変わり、押しながら回すと微調整できます。押すと動画を再生・一時停止できます。Side を軽く押すと速度が 1 倍に戻ります。
  • OBS 内の YouTube 動画を直接操作するには、セットアップで動画を入力し、OBS ブラウザソース URL をコピー をクリックして、そのアドレスを OBS のブラウザソースに貼り付けます。
  • Fadester で音楽に使う入力を割り当てます。Side を押したまま平たい Dial を回すと音量を調整できます。Top を押したままの Knob、Scroll、Dial は VJ レイヤー（ブレンドモードと不透明度）を操作します。選んでいないレイヤーは、初めて操作したときに放送中のシーンから自動で決まり（レイヤー 1 = いちばん上の見えている映像、レイヤー 2 = その次）、割り当てに保存されます。
  • Short を軽く押すと録画状態を確認できます（何も変更しません）。音量変更を元に戻す は Tour メニューにあります。

ミックス全体を調整する

セットアップ画面で OBS ミキサーの全入力をまとめて操作する設定を有効にし、設定を保存して操作を開始します。Side を押したまま Knob を回すとグループ全体の音量が変わります。Tour メニューから、ミックス全体を無音までフェードアウトしたり、前の音量に戻したりできます。ミュート済みの入力はそのままです。

困ったときは

バックグラウンド処理の診断メッセージは英語で表示されます。操作が反応しない場合は、TourBox Console の現在のプリセットと Fadester の操作履歴を確認してください。
