빠른 시작 · Windows x64

OBS Fadester for TourBox

TourBox로 OBS Studio 장면을 준비하고, 수동으로 페이드 전환하고, 음량을 조절할 수 있습니다.

TourBox를 OBS에 연결하기

  1. Windows용 ZIP 파일 전체를 풀고, 압축을 푼 폴더에서 Fadester for TourBox.exe를 실행합니다.
  2. OBS를 엽니다. TourBox Console의 프리셋 목록 옆에 있는 가져오기 버튼으로 presets/ko/OBS Fadester for TourBox.tb를 불러옵니다. 프리셋을 OBS에 연결하고 자동 전환(Auto Switch)을 켭니다. 프리셋은 사용할 언어로 된 파일 하나만 가져옵니다. Fadester의 TourBox Console로 가져오기 버튼을 사용하세요. .tb 파일을 더블 클릭하지 마세요.
  3. OBS의 도구 → WebSocket 서버 설정에서 인증을 켠 상태로 서버를 활성화합니다. OBS Studio 33.0.0 또는 33.0.1에서 수동 페이드를 사용하려면 스튜디오 모드를 켜고 페이드(Fade) 전환을 선택합니다. 미리 보기와 프로그램 사이의 흰색 슬라이더가 보이도록 둡니다.
  4. Fadester에서 OBS의 장면과 입력을 읽어 옵니다. 필요한 경우 OBS에서 설정한 포트와 암호를 입력합니다. TourBox Console에서 OBS Fadester for TourBox를 선택하고 Fadester에서 설정을 저장한 후 제어를 시작합니다. Fadester를 열어 둔 채 OBS 창으로 돌아갑니다.

Windows 표시 언어가 한국어가 아니면 Fadester를 닫고, 압축을 푼 폴더에서 PowerShell을 열어 & '.\Fadester for TourBox.exe' --language ko를 실행합니다.

서로 다른 두 장면으로 연습하기

  • Scroll 휠을 돌리면 미리 보기 장면만 바뀌고 프로그램은 그대로 유지됩니다. 휠을 누르면 두 장면의 이름이 패널에 표시됩니다.
  • 평평한 Dial을 천천히 돌리면 OBS 슬라이더가 움직이면서 두 장면이 섞입니다. 진행 중인 전환을 취소하려면 Side를 누른 상태에서 Dial을 누릅니다.
  • Chrome에서 YouTube 동영상을 재생합니다(무료 VJster 확장 프로그램 필요). 돌출된 Knob을 돌려 속도를 바꾸고, 누른 채 돌리면 미세 조정됩니다. 누르면 동영상 상태를 확인할 수 있습니다.
  • VJster는 Chrome의 YouTube만 제어하며 OBS의 YouTube 브라우저 소스는 제어할 수 없습니다. OBS에는 Chrome 윈도우 캡처로 표시하세요. 소리는 Chrome의 애플리케이션 오디오 캡처를 추가하세요.
  • Fadester에서 음악 입력을 지정합니다. Side를 누른 상태에서 평평한 Dial을 돌려 음량을 조절합니다. Top을 누른 상태의 Knob, Scroll, Dial은 VJ 레이어(블렌드 모드와 불투명도)를 조절합니다.

전체 믹스 조절하기

설정 화면에서 OBS 믹서의 모든 입력을 함께 제어하는 옵션을 켜고, 설정을 저장한 후 제어를 시작합니다. Side를 누른 상태에서 Knob을 돌리면 그룹 음량을 조절할 수 있습니다. Tour 메뉴에서 전체 믹스를 무음까지 페이드하거나 이전 음량으로 복원할 수 있습니다. 음소거된 입력은 음소거 상태를 유지합니다.

도움말

백그라운드 프로세스의 진단 메시지는 영어로 표시됩니다. 조작에 응답하지 않으면 TourBox Console의 활성 프리셋과 Fadester의 활동 기록을 확인하세요.
