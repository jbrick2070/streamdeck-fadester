VJster

VJster needs one free program on this computer: Fadester for OBS or the VJster plugin (for Stream Deck or OpenDeck), or Fadester Companion. Alone, this extension does nothing.

To let only this extension connect, paste the id into the VJster settings of Fadester for OBS, the VJster plugin or Fadester Companion.
