Midi Fadester auto-fade optional integration

This is the advanced shared-slot integration. For a normal OBS mixer-input fade, choose OBS Fade instead.

0 ms = instant. A T-bar return to 0 % cancels the throw. 50–20000 ms = timed fade following the slot's curve.

Without Visual Sidechain tempo, fires immediately with the millisecond fallback and shows NO TEMPO. Max wait 1 bar (4 s); press again to fire now, hold to cancel.
