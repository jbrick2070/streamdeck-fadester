# TourBox review notes, 2026-11-04 (historical)

These files are kept for the record. They predate bee7115, which drives
VJster from the one **OBS Fadester for TourBox** preset, so their
recommendation to ship two Windows presets (Show and Tools) and a separate
YouTube preset is superseded. Nothing here describes the current build; see
`tourbox/README.md` and `docs/vjster/TOURBOX.md` for that.

- `TOURBOX-YOUTUBE.md`: the 2026-11-04 design for a YouTube playback preset
  and VJster global commands ("a design, not a build").
- `YOUTUBE-RESEARCH.txt`: the research prompt that produced it.
- `kibitz-runs/`: the review-round receipts (r1 to r4) from the kibitz pass
  over the Windows TourBox controls, including the reviewers' quota and
  model records. Account identifiers and home-folder paths in these receipts
  were replaced with placeholders before they were committed here.
