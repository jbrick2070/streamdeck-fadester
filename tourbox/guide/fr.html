OBS Fadester for TourBox

Préparez les scènes, réalisez des fondus manuels et réglez le son d’OBS Studio avec votre TourBox.

Relier TourBox à OBS

  1. Décompressez toute l’archive ZIP Windows, puis lancez Fadester for TourBox.exe depuis le dossier extrait.
  2. Ouvrez OBS. Dans TourBox Console, utilisez Import à côté de Preset List pour importer presets/fr/OBS Fadester for TourBox.tb. Associez le préréglage à OBS et activez Auto Switch. Importez une seule version du préréglage.
  3. Dans OBS, ouvrez Outils → Paramètres du serveur WebSocket et activez le serveur avec l’authentification. Pour utiliser le fondu manuel dans OBS Studio 33.0.0 ou 33.0.1, activez le Mode studio, sélectionnez la transition Fondu (Fade) et laissez visible le curseur blanc entre Aperçu et Programme.
  4. Dans Fadester, cliquez sur Lire les scènes et entrées d’OBS. Saisissez le port et le mot de passe d’OBS si nécessaire. Pour essayer le réglage du volume, choisissez l’entrée musicale dans Affectations. Cliquez sur Enregistrer et démarrer, sélectionnez OBS Fadester for TourBox dans TourBox Console et revenez dans OBS. Gardez Fadester ouvert.

Si Windows est dans une autre langue, fermez Fadester et relancez-le depuis PowerShell dans le dossier extrait avec & '.\Fadester for TourBox.exe' --language fr.

Essayer avec deux scènes distinctes

  • Tournez la molette Scroll pour changer la scène dans Aperçu sans modifier Programme. Appuyez dessus pour afficher les noms des deux scènes dans le panneau.
  • Tournez doucement le Dial plat pour déplacer le curseur d’OBS et fondre les scènes. Pour annuler un fondu en cours, maintenez Side et appuyez sur Dial.
  • Lisez une vidéo YouTube dans Chrome (avec l’extension gratuite VJster). Tournez le Knob surélevé pour changer la vitesse ; appuyez et tournez pour des pas fins. Appuyez dessus pour lire l’état de la vidéo.
  • Choisissez une entrée musicale dans Fadester. Maintenez Side et tournez le Dial plat pour régler son volume. Avec Top maintenu, Knob, Scroll et Dial pilotent les calques VJ (mode de fusion et opacité).

Régler tout le mixage

Si les commandes sont actives, cliquez sur Arrêter les commandes. Dans Configuration, activez Piloter toutes les entrées du mixeur OBS, puis cliquez sur Enregistrer et démarrer. Maintenez Side et tournez Knob pour régler le groupe. Le menu Tour permet de baisser le mixage jusqu’au silence et de rétablir les niveaux précédents. Les entrées en sourdine le restent.

Aide

Les diagnostics du pont Fadester sont en anglais. Si une commande ne répond pas, vérifiez le préréglage actif dans TourBox Console et consultez l’onglet Activité de Fadester.
