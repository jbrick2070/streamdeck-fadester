OBS filter this control

Rides one filter setting on a dial, or turns a filter on and off, sets or steps a value from a key. Choose the source and its filter by name; the control follows the source through renames.

Any other number setting, a shader's own uniforms included, can be ridden once you type its range; choose it with care. OBS does not tell the deck which uniforms are lists: those named …_mode or marked as a list in the shader text are left out, any other you check yourself.

A write moves at most a tenth of the range, never a setting an Audio Modulator or a fader drives, and nothing of a Visual Sidechain filter while Panic is latched.
