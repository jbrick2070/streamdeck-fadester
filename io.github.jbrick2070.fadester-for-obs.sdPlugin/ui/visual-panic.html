Visual Panic this key

Sends Visual Sidechain's own Panic or Restore through OBS's hotkeys; OBS does not need to be in front.

This key needs the Visual Sidechain plugin in OBS. Try it once before the show: hold Restore. If the key then says Visual Sidechain missing, OBS has no Visual Sidechain.

Every Panic press is sent. Panic keys show PANIC SENT until a Restore is accepted or OBS reconnects; meanwhile no Visual Sidechain filter is written from the deck. A Restore with no Panic before it changes nothing.
