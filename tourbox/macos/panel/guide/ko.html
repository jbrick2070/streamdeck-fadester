Fadester Companion

TourBox로 OBS Studio의 장면을 준비하고, 직접 페이드하고, 소리를 조절하세요.

처음 열 때

Fadester Companion.app을 응용 프로그램 폴더로 옮깁니다. 이 앱은 Apple의 공증을 받지 않았으므로 처음에는 macOS가 열지 않습니다. 한 번 열어 본 후 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 클릭합니다. (macOS 14까지는 Control 키를 누른 채 앱을 클릭하고 열기를 선택해도 됩니다.)

TourBox를 OBS에 연결하기

  1. OBS의 도구 → WebSocket 서버 설정에서 인증을 켠 상태로 서버를 활성화합니다. OBS Studio 33에서 수동 페이드를 사용하려면 스튜디오 모드를 켜고 페이드(Fade) 전환을 선택합니다. 미리 보기와 프로그램 사이의 흰색 슬라이더가 보이도록 둡니다. OBS에 저장된 암호는 Fadester Companion이 직접 읽어 옵니다.
  2. Fadester Companion에서 TourBox Console로 가져오기를 클릭합니다. 사용하는 언어의 프리셋이 다운로드 폴더에 저장되고, 그 경로가 복사되며, TourBox Console이 열립니다(클릭할 곳 보기가 클릭 순서를 보여 줍니다).
  3. TourBox Console에서 프리셋 목록 옆의 가져오기 아이콘을 클릭합니다. 파일 창에서 ⌘⇧G를 누른 다음 ⌘V와 Return을 누르면 그 파일로 바로 이동합니다. 창이 이 단축키를 받지 않으면 다운로드 폴더에서 파일을 직접 선택하세요. OBS Fadester for TourBox.tb(다운로드 폴더에 이전 사본이 이미 있으면 OBS Fadester for TourBox 2.tb: 앱이 저장한 파일 이름을 알려 줍니다)를 연 다음, Auto Switch를 끄고 OBS Fadester for TourBox를 선택합니다. 그러면 앞에 있는 앱과 관계없이 프리셋 하나로 작동합니다. Auto Switch를 켜 둘 때만 Not Linked를 클릭해 OBS를 선택하고 Save를 클릭하며, Chrome이 앞에 있을 때 동영상을 제어하려면 Google Chrome에도 연결합니다. 한 가지 언어 버전만 가져오고, Windows용 파일은 가져오지 마세요.
  4. Fadester Companion에 손쉬운 사용 허용…를 클릭하고 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Fadester Companion을 켭니다. Fadester Companion T-bar와 Fadester Companion Shortcuts도 보이면 함께 켭니다. TourBox Console에는 별도의 권한이 필요합니다.
  5. 할당에서 장면과 음악 입력을 선택합니다. 손쉬운 사용 권한이 허용되면 컨트롤은 자동으로 시작됩니다. 컨트롤: 켜짐이 표시될 때까지 기다립니다(표시등이 꺼짐이면 그 옆의 시작을 클릭합니다). 창을 닫아도 컨트롤은 중지되지 않습니다. 앱은 화면 오른쪽 위 메뉴 막대에 남아 있습니다.

Mac용 프리셋은 OBS 동작에 Control + Option + Shift를, 동영상과 레이어 동작에 Control + Shift 또는 Option + Shift를 사용합니다. Command는 사용하지 않습니다.

서로 다른 두 장면으로 연습하기

  • Scroll 휠을 돌리면 미리 보기 장면만 바뀌고 프로그램은 그대로 유지됩니다. 휠을 누르면 두 장면의 이름이 활동 로그 탭에 표시됩니다.
  • 평평한 Dial을 천천히 돌리면 OBS 슬라이더가 움직이면서 두 장면이 섞입니다. 진행 중인 전환을 취소하려면 Side를 누른 상태에서 Dial을 누릅니다. 시계 방향으로 돌리면 다음 전환에서도 항상 T-바가 미리 보기 쪽으로 움직입니다. 전환이 끝나면 잠시 기다린 후 다시 돌리세요.
  • Chrome에서 YouTube 동영상을 재생합니다(무료 VJster 확장 프로그램 필요). 돌출된 Knob을 돌려 속도를 바꾸고, 누른 채 돌리면 미세 조정됩니다. 누르면 동영상을 재생하거나 일시 정지합니다. Side를 짧게 누르면 속도가 1배로 돌아갑니다.
  • OBS 안의 YouTube 동영상을 직접 제어하려면 설정에서 동영상을 입력하고 OBS 브라우저 소스 URL 복사를 클릭한 다음, 그 주소를 OBS 브라우저 소스에 붙여 넣습니다.
  • Fadester에서 음악 입력을 지정합니다. Side를 누른 상태에서 평평한 Dial을 돌려 음량을 조절합니다. Top을 누른 상태의 Knob, Scroll, Dial은 VJ 레이어(블렌드 모드와 불투명도)를 조절합니다. 선택하지 않은 레이어는 처음 사용할 때 현재 방송 중인 장면에서 자동으로 채워지고(레이어 1 = 맨 위의 보이는 화면, 레이어 2 = 그 아래 화면) 할당에 저장됩니다.
  • Short를 짧게 누르면 녹화 상태만 확인합니다. 오디오 변경 실행 취소는 Tour 메뉴에 있습니다.

전체 믹스 조절하기

설정 화면에서 OBS 믹서의 모든 입력을 함께 제어하는 옵션을 켜고, 설정을 저장한 후 제어를 시작합니다. Side를 누른 상태에서 Knob을 돌리면 그룹 음량을 조절할 수 있습니다. Tour 메뉴에서 전체 믹스를 무음까지 페이드하거나 이전 음량으로 복원할 수 있습니다. 음소거된 입력은 음소거 상태를 유지합니다.

도움말

백그라운드 프로세스의 진단 메시지는 영어로 표시됩니다. 조작에 응답하지 않으면 TourBox Console의 활성 프리셋과 Fadester의 활동 기록을 확인하세요.

TourBox로 OBS를 완전히 제어하는 기능은 아직 Mac에서 리허설로 확인되지 않았습니다. 방송 전에 테스트 장면으로 연습하세요.

macOS가 다른 언어를 사용하면 Fadester Companion을 종료하고 터미널에서 open -a "Fadester Companion" --args --language ko를 실행합니다.
