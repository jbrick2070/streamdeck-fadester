The translations were made with an AI model and checked by a second AI model. No native speaker has reviewed them yet; corrections are welcome as an issue or pull request. Button and setting names are the ones the plugin shows in each language (`io.github.jbrick2070.fadester-for-obs.sdPlugin/<language>.json`). Stream Deck itself has no Italian, Dutch, Brazilian Portuguese, Russian or Turkish, so in those languages its action list shows the English action names.
